# Data Processing

Client and synthetic data generation for the Python data-processing service.

## Synthetic data

Tests in this module must not depend on captured real payloads. Instead, use the deterministic generator in `synthetic-data.generator.ts` or the shared fixtures in `synthetic-fixtures.ts`.

- Every generator accepts a `seed` and is reproducible across runs.
- Rare / adversarial cases are generated deliberately:
  - `marketData({ zeroVolumeDay })` for malformed injests.
  - `marketData({ flashCrashDay })` for extreme market moves.
  - `marketData({ gapUpDay })` for gap opens.
  - `sentiment({ forceLabel, includeMalformed })` for classifier edge cases.
  - `news({ includeDuplicates })` for deduplication tests.

## Personal-data policy

The Wave 9 personal-data policy prohibits committing real user or market content to the repository. Any fixture in this directory must be generated by the synthetic generator. If a captured payload is found, replace it with an equivalent synthetic fixture and note the replacement in the PR.

## Usage

```ts
import { SyntheticDataGenerator } from './synthetic-data.generator';

const gen = new SyntheticDataGenerator();
const candles = gen.marketData({ seed: 'test', flashCrashDay: 2 });
const sentiment = gen.sentiment({ seed: 'test', forceLabel: 'negative' });
```
