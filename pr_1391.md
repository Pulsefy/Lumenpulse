## Summary

Surfaces the market signals feed on the dashboard by consuming the backend `GET /signals/latest` endpoint. Previously, the `SignalsController` exposed signal data that no frontend client consumed, despite being a core platform differentiator.

A `SignalsPanel` component is now rendered on the dashboard, showing each signal's type (category), subject (title), strength (severity), and timestamp (generation time). The panel is independently refreshable via its own hook with staleness detection. Each signal links through to the asset it references (matched against portfolio holdings) or falls back to the dashboard view. Loading, empty, and error states all use the shared `ListSkeleton`, `EmptyState`, and `ListError` components.
